Photo folder & index

By default the index lives in .photoindex/ inside the folder you pick. For a NAS library, keep it on this Mac instead: writes stay off the share and search still works when the NAS is asleep.
Photos are identified by the file itself, not by where you point the picker, so you can scan a subfolder today and the whole library tomorrow and still end up with one index. Scan scope is an optional shortcut for working through a large library folder by folder without re-walking all of it.

Scan settings

File-stat concurrency matters most on a NAS: reading size and modified time is one round trip per file, so raise it for SMB shares.

Dates, places and events

Place names come from an offline GeoNames-derived list, downloaded once and cached in .photoindex/geo/. No online geocoding service is ever called.
Use this when a file's EXIF holds an export date rather than the day it was taken. An override wins over every other source. Re-scan those files to apply it.

Backups

Copies records.jsonl, vectors.bin and the config into .photoindex/backups/. Thumbnails are excluded on purpose: they are most of the index and can be rebuilt from the originals without any model calls, whereas every record cost ~21 seconds of scanning.
